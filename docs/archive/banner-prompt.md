# ApexOS Banner — Image Generation Prompt

## Prompt

```
Wide banner image, 1600x400px. A Raspberry Pi 5 circuit board seen at a slight 
angle, glowing with deep cyan-green light from underneath. Floating above it: 
multiple semi-transparent dark terminal windows showing streaming text, a thermal 
camera heatmap in blue-to-red, waveform audio visualization, and a small 
windowed desktop OS interface. The aesthetic is cyberpunk-minimal — near-black 
background (#0a0a0f), neon green (#00ff88) and electric cyan (#00d4ff) accents, 
very subtle grid overlay, no clutter. Small text reads "APEXOS" in a monospace 
font top-left. The mood: a quiet machine that is awake and aware. Cinematic 
lighting, sharp details, no people.
```

## Style notes
- Background: near-black `#0a0a0f` matching the UI
- Primary accent: `#00ff88` (the green from the UI topbar)
- Secondary: `#00d4ff` cyan for sensor/thermal elements  
- NOT: glowing robot hands, humanoid AI, blue Matrix rain
- YES: hardware + UI + data, the Pi as a brain stem
